  Body/UI:  "DM Sans" (weights 400, 500) — import from Google Fonts
  Mono/Data:"JetBrains Mono" — for numbers, codes, measurements

    display: 3.5rem / 700 / tracking -0.03em
    h1: 2.25rem / 600 / tracking -0.02em

    h3: 1.125rem / 600
    body: 0.9375rem / 400 / line-height 1.65

Layout Principles:
  - Left-aligned content throughout. No centered hero text.
  - Glassmorphism cards: background rgba(14,21,37,0.8), border 1px solid 
    var(--border), backdrop-filter blur(12px)
  - Border radius: 12px for cards, 8px for buttons, 6px for inputs, 
    24px for pills/badges
  - Spacing grid: 4px base unit. Use 8, 12, 16, 24, 32, 48, 64
  - Max content width: 1280px, centered with auto margins
  - Sidebar: 240px fixed, content area takes remaining width

Motion Rules (restrained and purposeful):
  - ONE signature animation: the scan-beam sweeping across uploaded images
  - Step pipeline: sequential reveal with 200ms staggered delay per step
  - Page transitions: 200ms opacity fade only
  - Counters: animate from 0 to final value on mount (1.5s ease-out)
  - NO scroll-triggered animations, NO hover float effects on cards
  - Micro-interactions only: button press scale(0.97), input focus glow

Call the Anthropic API from your frontend or a lightweight backend.
Use this exact request structure:

const response = await fetch("https://api.anthropic.com/v1/messages", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    model: "claude-sonnet-4-6",
    max_tokens: 1500,
    messages: [{
      role: "user",
      content: `You are MetroScan AI, an automated Legal Metrology compliance 
      officer for India. A product label has been scanned.
      
      Product context: ${productName || "Unknown packaged commodity"}.
      Upload type: ${uploadType} (physical/ecommerce/manufacturer).
      
      Simulate a realistic, detailed compliance check under Legal Metrology 
      (Packaged Commodities) Rules 2011 + 2017 amendment for a typical 
      Indian FMCG product. 
      
      Return ONLY a valid JSON object (no markdown, no preamble) with this 
      exact structure:
      {
        "productName": "string — inferred product name",
        "overallCompliant": boolean,
        "complianceScore": number (0-100),
        "violationCount": { "critical": number, "major": number, "minor": number },
        "processingTimeMs": number (between 35000 and 58000),
        "barcodeCalibration": {
          "detected": true,
          "pixelWidth": number (250-400),
          "mmPerPx": number (0.06-0.12, 4 decimal places),
          "confidence": number (85-99)
        },
        "fields": [
          {
            "id": "name_of_commodity",
            "label": "Name of Commodity",
            "ruleRef": "Rule 6(1)",
            "status": "compliant" | "violation" | "warning",
            "severity": "critical" | "major" | "minor" | null,
            "found": "string — what was found on label",
            "required": "string — what the rule requires",
            "fontSizeMm": number or null,
            "fontRequiredMm": number or null,
            "notes": "string — officer observation"
          }
        ],
        (include all 12 fields: name_of_commodity, net_quantity, mrp, 
         date_of_manufacture, best_before, manufacturer_address, country_of_origin, 
         customer_care, consumer_complaint_address, common_name, 
         quantity_dimensions, fssai_number),
        "semanticFlags": ["string — any contextual issues found"],
        "officerRecommendation": "string — 2-3 sentence enforcement recommendation",
        "certificateEligible": boolean
      }
      
      Make it realistic: most products have 1-3 violations. Use specific, 
      believable values (real font sizes, real addresses, real MRP formats). 
      Vary severity across fields.`
    }]
  })
});

const data = await response.json();
